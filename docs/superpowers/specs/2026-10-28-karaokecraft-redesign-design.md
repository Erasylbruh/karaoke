# KaraokeCraft — редизайн «Сцена»

Дата: 2026-10-28 · Статус: дизайн согласован в чате, спецификация на ревью.

## 1. Цель и рамки

Запрос: сделать сайт красивее, удобнее и приятнее.

Критерии успеха:
1. Единый визуальный язык на всех страницах: один акцент (янтарь), один логотип, одна типографика. Зелёного «спотифай»-стиля нигде нет.
2. На ширине 375px ни одна страница не прокручивается горизонтально.
3. Нет ошибок гидратации. Вошедший пользователь не видит мигания «Войти» / «Нет доступа» / «Ничего не нашли».
4. Исправлены баги удобства из §7.
5. Режим «На слух» в студии работает.
6. Проходят `npm test`, `npm run lint` и `npm run build`.

Подтверждённые допущения:
- Это демо-прототип. Данные лежат в localStorage, моки, быстрый вход и «Сменить роль» остаются.
- Без сохранённого входа пользователь — администратор, как сейчас.
- Интерфейс русский, тема тёмная.
- Модель данных (`lib/types.ts`) и ключи localStorage не меняются. Тип `FontFamily` только расширяется новыми ключами.

Вне рамок: настоящий бэкенд и авторизация, загрузка аудиофайлов, светлая тема, i18n, новые разделы.

## 2. Принятые решения

| Вопрос | Решение |
| --- | --- |
| Визуальное направление | «Сцена»: развитие текущего бренда (тёмная тема, янтарь, Unbounded + Onest) |
| Система стилей | Tailwind v4: токены в `@theme`, общие UI-компоненты; сложные эффекты — именованные классы в `app/globals.css` |
| Режим «На слух» | Реализовать запись таймингов тапами |
| Вход | Только страницы `/login` и `/register`; модалка входа из шапки удаляется |
| Тесты | Встроенный `node --test` для чистой логики, без новых зависимостей |

## 3. Дизайн-система

### 3.1 Токены (`app/globals.css`, `@theme`)

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--color-ink` | `#0B0A10` | фон страницы |
| `--color-surface-1/2/3` | `#14121B` / `#1C1A25` / `#262331` | карточки, панели, поля / hover |
| `--color-line` | `rgb(255 255 255 / .08)` | разделители, рамки |
| `--color-line-strong` | `rgb(255 255 255 / .16)` | рамки при наведении |
| `--color-fg` | `#F4F4F5` | основной текст |
| `--color-fg-muted` | `#A1A1AA` | вторичный текст (7,7:1 на ink) |
| `--color-fg-subtle` | `#8B8B95` | метаданные (5,8:1 на ink, 5,1:1 на surface-2) |
| `--color-accent` | `#FFB547` | основной акцент |
| `--color-accent-ink` | `#1C1305` | текст на акценте (10,4:1) |
| `--color-accent-soft` | `rgb(255 181 71 / .14)` | подложки бейджей и выделений |
| `--color-danger` / `--color-success` | `#F87171` / `#4ADE80` | ошибки / успех |

- Шрифты подключаются через `next/font/google` (`subsets: ['latin','cyrillic']`) как CSS-переменные на `<html>`: `--font-display` (Unbounded) и `--font-sans` (Onest). `<link>` на Google Fonts удаляется.
- Типографика: основной текст 15–16px, служебный не меньше 13px. Заголовки — Unbounded 600–700.
- Радиусы: 10px — поля, 16px — карточки, 24px — крупные панели, 999px — кнопки и чипы.
- Всплывающие слои: тень `0 12px 32px rgb(0 0 0 / .45)`, фон `surface-2`, рамка `line`.
- Фокус у всех интерактивных элементов: `outline: 2px solid accent; outline-offset: 2px`.
- Все анимации отключаются при `prefers-reduced-motion: reduce`.
- Утилита `wrap`: `max-width: 1280px`, горизонтальные поля 16 / 24 / 40px (до 640 / до 1024 / шире). Её используют шапка, страницы и футер.

### 3.2 UI-компоненты (`components/ui/`)

- `buttonStyles({ variant, size })` возвращает строку классов. Варианты: `primary` (янтарь), `secondary` (surface + рамка), `ghost`, `danger`. Размеры: `sm`, `md`, `lg`. Используется в `Button` (`<button>`) и для `<Link>`.
- `IconButton` — круглая кнопка, `aria-label` обязателен.
- `Field` (подпись, подсказка, ошибка) и стилизованные `Input`, `Textarea`, `Select`. Ошибка связана с полем через `aria-describedby`.
- `Segmented` — группа взаимоисключающих вариантов, стрелки клавиатуры переключают. Два режима:
  - `radio` (`role="radiogroup"`) — сортировка, формат;
  - `tabs` (`role="tablist"` / `tab` + `aria-controls`) — вкладки профиля, админки и студии.
- `Chip` — переключаемая метка с `aria-pressed`.
- `Modal` на нативном `<dialog>` + `showModal()`: фокус, Esc и неактивный фон даёт браузер, клик по подложке закрывает. Заголовок, кнопка закрытия.
- `Menu` — кнопка и выпадающий список. Закрывается по Esc и клику снаружи, при открытии фокус переходит на первый пункт.
- `Avatar` — картинка с запасным вариантом (инициалы на цвете из хэша имени) при отсутствии `src` или ошибке загрузки.
- `ToastProvider` + `useToast()` — один тост за раз, `role="status"`, `aria-live="polite"`. Заменяет две копии логики тостов.
- `Skeleton` — блок-заглушка: мерцание, без анимации при reduced-motion.
- `LyricCover` (`components/karaoke/`) — обложка-«кадр» трека в его стиле (фон, шрифт, акцент, 2–3 строки текста). Параметры: `track`, `size`, `animated`. Используется в каталоге, профиле, плеере, админке и на странице входа.

### 3.3 Общая логика (`lib/`)

Чистые модули без зависимостей от React и DOM, покрываются тестами:
- `format.ts`: `formatCount` (960 → «960», 1840 → «1,8 тыс.», 2 400 000 → «2,4 млн»), `formatTime` (секунды → «m:ss»), `formatDate` (ISO → «14 окт. 2026»), `plural` (7 → «7 треков»).
- `lrc.ts`: `parseLrc(text) → LyricLine[]` (сортировка по времени, пропуск пустых строк и мусора), `toLrc(lines) → string`, `formatLrcTimestamp(sec) → "[mm:ss.xx]"`.
- `lyrics.ts`: `activeLineIndex(lines, t)`, `lineProgress(lines, index, t, duration) → 0..1` (заливка завершается на 90% длительности строки, как сейчас).
- `tap-sync.ts`: состояние записи «На слух». `createTapSession(texts)`, `tap(session, t)`, `undoTap(session)`, `isComplete(session)`, `toLyricLines(session) → LyricLine[]`.

Модули с браузерной логикой:
- `app/fonts.ts` — объекты `next/font`: два шрифта интерфейса с `preload: true` и четыре шрифта стилей (Playfair Display, Caveat, Russo One, JetBrains Mono) с `preload: false`.
- `lib/fonts.ts` — единая таблица стилей шрифта: ключ → `{ label, family }`. Ключи: `Onest`, `Unbounded`, `Playfair`, `Caveat`, `Russo`, `Georgia`, `Mono`; неизвестный ключ → `Onest`. `family` берётся из `font.style.fontFamily`, поэтому плеер, студия и canvas-экспорт рисуют одними и теми же реальными шрифтами.
- `lib/palettes.ts` — пресеты палитр `{ name, background, text, active }`: «Ночь», «Море», «Закат», «Неон», «Лес», «Сепия».
- `lib/store.ts` — внешнее хранилище поверх `lib/storage.ts` для `useSyncExternalStore`. На сервере и при гидратации снимок `null` («ещё неизвестно»), после гидратации — реальные данные. Подписка обновляется при изменениях в этой вкладке и по событию `storage` из других вкладок. Хуки: `useCurrentUser()` (через `AuthContext`), `useKaraokes()`.

### 3.4 Каркас

- `app/layout.tsx`: шрифты, `AuthProvider`, `ToastProvider`, `SiteHeader`, `<main>`, `SiteFooter`. `body` — колонка на всю высоту, футер прижат к низу.
- `SiteHeader` — sticky, фон `ink/70` с `backdrop-blur`, нижняя линия `line`.
  - Десктоп: логотип · «Каталог» · «Студия» · пустое место · кнопка «Создать» (primary) · аватар-меню.
  - Телефон (<768px): логотип · `IconButton` «+» · аватар-меню.
  - Меню аватара: имя и @username, «Профиль», «Админка» (для админа), «Сменить роль (демо)», «Выйти».
  - Без входа вместо аватара кнопка «Войти» → `/login?next=<текущий путь>`. Пока состояние неизвестно — круглый `Skeleton`.
  - На странице плеера шапка прозрачная и без линии, поверх цвета трека.
- `SiteFooter` — одна строка в `wrap`: логотип, «Каталог», «Студия», «Профиль», © 2026. На странице плеера не показывается.

## 4. Страницы

### 4.1 Каталог `/`
- Первый экран: заголовок (Unbounded), подзаголовок, поиск с иконкой и подсказкой клавиши «/» (фокус по «/»), чипы тегов, собранные из данных. Справа — витрина: рекомендованный трек с наибольшим `recommendationScore` в `LyricCover` с бегущей заливкой строки; клик открывает плеер. На телефоне витрина идёт под поиском и становится ниже.
- Панель: `Segmented` с сортировкой («Рекомендуем», «Популярные», «Новые», «Старые»), активный тег, «Сбросить» и счётчик («7 треков»).
- Состояние хранится в URL: `?q=`, `?tag=`, `?sort=` через нативный History API, который Next 16 синхронизирует с `useSearchParams`:
  - поиск — `history.replaceState` с задержкой 300 мс;
  - тег и сортировка — `history.pushState`, чтобы «Назад» отменял фильтр.
- Сетка: 2 колонки до 640px, далее авто (`minmax(200px, 1fr)`), до 5 колонок. Карточка — ссылка: `LyricCover` (квадрат), название, артист, ♥ и ▶ счётчики. При наведении карточка приподнимается, строка в обложке начинает «петься», появляется круглая ▶. Бейджи: «★ Выбор редакции» и длительность.
- Пока данные не прочитаны — 8 скелетон-карточек. Пустой результат — сообщение и «Сбросить фильтры».

### 4.2 Плеер `/karaoke/[id]`
- Фон — цвет трека с мягким радиальным свечением цветом акцента. Текст — цвет текста трека.
- Десктоп (≥1024px): слева (≈340px, sticky) `LyricCover`, название, артист, «Автор: …», теги и ряд действий: ♥ со счётчиком, «Поделиться» (копирует ссылку, тост), «Скачать видео» (модалка экспорта), «Отзывы (N)». Справа — текст песни.
- Телефон: сверху строка «← · мини-обложка · название/артист · ♥ · ⋯». В меню «⋯»: «Поделиться», «Скачать видео», «Отзывы». Текст на всю высоту между шапкой и панелью управления.
- Текст песни: каждая строка — `<button>`. Активная строка с заливкой (`lineProgress`) по центру, прошедшие — 50% непрозрачности, будущие — 30%. Клик или Enter переходит к строке и запускает воспроизведение. После перемотки активная строка центрируется. Если пользователь прокрутил текст сам, автоцентрирование ждёт 3 секунды.
- Часы воспроизведения: `requestAnimationFrame` и `performance.now()` вместо `setInterval(100)`.
- Панель управления (фиксирована снизу, стекло): ▶/❚❚, −5 с, +5 с, прогресс (range) с текущим временем и длительностью, громкость (иконка и ползунок, на телефоне только иконка mute). Клавиши: Пробел — пауза/воспроизведение, ← / → — ±5 с; не срабатывают, когда фокус в поле ввода.
- Отзывы — боковая панель справа (на телефоне — нижняя шторка) с `CommentsSection`.
- Трека нет — экран «Караоке не найдено» с кнопкой «В каталог». Пока данные не прочитаны — скелетон.

### 4.3 Студия `/create`
- Десктоп: слева колонка блоков, справа sticky-предпросмотр. Телефон: сначала предпросмотр (ниже по высоте), затем блоки.
- Блок «Трек»: название (обязательно, ошибка у поля), артист, описание, теги (ввод через запятую или Enter → чипы с удалением).
- Блок «Текст и тайминги» — вкладки `Segmented`:
  - «LRC»: загрузка `.lrc/.txt`, редактор LRC (моноширинный), число распознанных строк, ошибка, если строк нет.
  - «На слух»: см. §5.
- Блок «Стиль»: шрифт — сетка образцов «Аа» в своих шрифтах (7 вариантов); палитры — пресеты кружками-превью и три поля «Фон», «Текст», «Активная строка»; размер текста (20–56px); формат 9:16 / 16:9.
- Предпросмотр: рамка формата с фоном, текстом и водяным знаком, проигрывается по реальным таймингам (▶/❚❚, перемотка, время), строки окна прокручиваются вокруг активной.
- Нижняя sticky-панель: «Скачать видео» (secondary) и «Опубликовать» (primary). После публикации — тост и переход в плеер нового трека.

### 4.4 Профиль `/profile`
- Пока состояние неизвестно — скелетон. Без входа — приглашение: «Войдите, чтобы видеть свои треки» и «Войти».
- Карточка: `Avatar` 88px, имя, бейдж «Администратор», @username · email, био, «Создать трек». Статистика (`formatCount`): треков, лайков получено, прослушиваний.
- Вкладки `Segmented`: «Мои треки (N)», «Понравившиеся (N)», «Настройки». Сетки — те же карточки, что в каталоге. Пустые состояния с действием.
- «Настройки»: имя, о себе, URL аватара с живым превью, «Сохранить» → «Сохранено» рядом с кнопкой.

### 4.5 Админка `/admin`
- Пока состояние неизвестно — скелетон. Не админ — карточка «Нужны права администратора» и «Войти как администратор» (демо).
- Плитки: треков, пользователей, лайков, прослушиваний (`formatCount`).
- Вкладки: «Треки», «Пользователи», «Система».
  - «Треки»: поиск, таблица (мини-`LyricCover`, название/артист, автор, ♥/▶, чип «★ Выбор редакции», «Открыть», «Удалить»).
  - «Пользователи»: `Avatar`, имя/@username, email, роль-бейдж, дата, «Сделать админом»/«Снять админа», «Удалить» (кроме себя).
  - «Система»: информационные карточки как сейчас, в новом стиле.
- Удаление подтверждается через `Modal`. До 768px строки таблиц показываются карточками.

### 4.6 Вход `/login` и регистрация `/register`
- Две колонки на десктопе: форма и витрина (`LyricCover` с анимацией и слоган). На телефоне — только форма.
- Вход: одно поле «Имя пользователя или email» и пароль (демо: пароль не проверяется). Демо-кнопки «Войти как Лиза (пользователь)» и «Войти как администратор» используют существующих пользователей `user-liza` и `user-admin`. После входа — переход на `next` или `/`.
- Поиск пользователя — по `username` или `email` без учёта регистра. Неизвестное значение создаёт пользователя один раз, с ролью `user`:
  - если в значении есть «@» — это email, а `username` берётся из части до «@»;
  - иначе это `username`, а email — `<username>@karaokecraft.demo`.

  Повторный вход тем же значением находит созданного пользователя, а не плодит дубликат.
- Регистрация: имя*, имя пользователя, email*, пароль*; ошибки у полей.

### 4.7 Отзывы (`CommentsSection`)
- Форма: имя (для гостя), текст, «Отправить» (primary, sm). Список: `Avatar`, имя, дата (`formatDate`), текст, «Удалить» (автор или админ).

## 5. Режим «На слух»

1. Поле «Текст песни» — обычные строки, по одной на строку караоке; пустые строки игнорируются. Сначала заполнено текущим текстом.
2. «Начать запись» запускает фоновую музыку с 0 и часы. Показываются текущая строка (крупно), следующая (тускло) и счётчик «3 / 10».
3. Тап (кнопка «Тап» или Пробел) отмечает начало очередной строки текущим временем. «Отменить» (или Backspace) снимает последнюю отметку.
4. Когда отмечены все строки, запись останавливается. Строки получают времена, LRC пересобирается через `toLrc`, открывается вкладка «LRC», тост «Тайминги записаны».
5. «Стоп» до конца останавливает запись без изменений и показывает сообщение «Отмечено 6 из 10 — запишите заново».
6. Длительность трека при публикации: `max(10, время последней строки + 4)` секунд.

## 6. Экспорт видео (`VideoDownloaderModal`)
- На общем `Modal`. Начальный формат приходит из кнопки (исправление бага), переключатель — карточки форматов («Вертикальное 9:16 — Reels, Shorts, TikTok», «Горизонтальное 16:9 — YouTube»).
- Запись: прогресс-бар и проценты, «Отмена». Готово: превью `<video>`, «Скачать .webm», «Записать заново». Отдельно — «Скачать кадр .png».
- Canvas рисует шрифтом трека (`lib/fonts.ts`), перед записью ждёт `document.fonts.load(...)`. Водяной знак «✦ KaraokeCraft» не меняется.

## 7. Исправляемые баги (чек-лист)
1. Шапка шириной 616px на экране 375px — горизонтальная прокрутка на всех страницах.
2. Ошибка гидратации в шапке; мигание «Войти» и «Требуются права администратора» у вошедшего.
3. Мигание «Ничего не нашли» на главной до чтения данных.
4. Модалка входа просит имя, а ищет email; демо-кнопки на `/login` используют несуществующие email и плодят дубликаты.
5. В меню пользователя нет «Профиля»; меню и модалки не закрываются по Esc и клику снаружи.
6. Плеер: «Видео 16:9» открывает 9:16; после перемотки активная строка не по центру; подсветка шагами по 100 мс; строки недоступны с клавиатуры.
7. Профиль: битые аватары авторов; числа без форматирования.
8. Студия: «На слух» не работает; «Опубликовать» спрятано внизу; предпросмотр не по реальным таймингам.
9. В таблице шрифтов плеера есть Inter и Outfit, но они не загружаются.
10. Футер не прижат к низу на коротких страницах.

## 10. Риски
- `cacheComponents: true` пре-рендерит клиентские страницы. Всё, что читает localStorage, должно идти через `lib/store.ts` (серверный снимок `null`), иначе вернутся ошибки гидратации и мигания.
- `next/font` генерирует свои имена семейств. Нигде нельзя писать `"Onest"` строкой: только `fonts.*.style.fontFamily` через `lib/fonts.ts`.
- Проект не в git — откатиться нечем. Перед реализацией с согласия пользователя: `git init` и базовый коммит текущего состояния.
- Dev-сервер соседней сессии («Запуск сайта для проверки») следит за той же папкой и подхватит изменения. Для проверки используется он же.
