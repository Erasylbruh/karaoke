# Следующие задачи

Список согласованных идей, которые ещё не сделаны. Закрытую задачу удаляйте из списка. Аудит и шаги к релизу — в [RELEASE.md](RELEASE.md).

## Видео

Вертикальное видео v2 и оба горизонтальных варианта уже сделаны: [video/vertical-v2.md](video/vertical-v2.md), [video/horizontal.md](video/horizontal.md).

1. **Фрагмент вместо всей песни.** В меню «Скачать» выбор «Вся песня / Фрагмент 30 с». Начало фрагмента предлагать по первому повтору припева (строка, которая чаще всего встречается в тексте), давать подвинуть.
2. **Проверка контраста.** Если цвет заливки или текста почти сливается с фоном, предупреждать в редакторе стиля.

## Обложка

Окно обрезки с превью, размер 768×768, загрузка файлом в Supabase и сообщение для HEIC сделаны (`lib/cover.ts`, `components/karaoke/CoverCropModal.tsx`).

3. **Разрешить картинки в бакете и перенести старые обложки.** Выполнить в Supabase → SQL Editor `supabase/storage.sql` (он разрешает `image/jpeg`, `image/png`, `image/webp`), затем в админке «Треки» нажать «Перенести обложки». До этого новые обложки, как раньше, сохраняются внутри трека.

## Перед ростом аудитории

4. **Принудительный App Check для Firestore.** Клиентская часть готова и включается ключом (docs/FIREBASE.md, «App Check»). Чтобы нажать Enforce, сначала перевести вызовы REST без токена App Check: `lib/server-meta.ts`, проверку бана в `lib/server/storage.ts`, запись адреса в `aligner/src/tunnel.rs`.
5. **Чтение по страницам** вместо подписки каждого посетителя на все коллекции (`lib/store.ts`): иначе бесплатные 50 000 чтений в день кончатся при сотнях посетителей.
6. **Счётчики на сервере** (Cloud Functions, нужен Blaze): `viewsCount`, `likesCount`, `recommendationScore`, `events`.
7. **Сервис авто-тайминга на сервере** вместо Cloudflare Quick Tunnel с домашнего ПК (Cloudflare пишет, что Quick Tunnels только для тестов). Готовы `aligner/Dockerfile` (не проверен) и обязательная проверка токена вне `127.0.0.1`; осталось выбрать сервер, собрать образ, поставить HTTPS-прокси и задать `NEXT_PUBLIC_ALIGNER_URL` (aligner/README.md, «На сервере»).
