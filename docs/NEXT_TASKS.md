# Следующие задачи

Список согласованных идей, которые ещё не сделаны. Закрытую задачу удаляйте из списка.

## Видео

Вертикальное видео v2 и оба горизонтальных варианта уже сделаны: [video/vertical-v2.md](video/vertical-v2.md), [video/horizontal.md](video/horizontal.md).

1. **Фрагмент вместо всей песни.** В меню «Скачать» выбор «Вся песня / Фрагмент 30 с». Начало фрагмента предлагать по первому повтору припева (строка, которая чаще всего встречается в тексте), давать подвинуть.
2. **Проверка контраста.** Если цвет заливки или текста почти сливается с фоном, предупреждать в редакторе стиля.

## Обложка

Окно обрезки с превью, размер 768×768, загрузка файлом в Supabase и сообщение для HEIC сделаны (`lib/cover.ts`, `components/karaoke/CoverCropModal.tsx`).

3. **Разрешить картинки в бакете и перенести старые обложки.** Выполнить в Supabase → SQL Editor команду `update storage.buckets …` из конца `supabase/storage.sql`, затем в админке «Треки» нажать «Перенести обложки». До этого новые обложки, как раньше, сохраняются внутри трека.
