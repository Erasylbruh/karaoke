# Aligner: автоматическая расстановка таймингов

Небольшой сервис на Rust, который работает на вашем компьютере. Редактор сайта отправляет ему аудио и текст песни, а получает начало и конец каждой строки (и каждого слова).

Как работает:
1. Аудио (mp3, m4a/aac, ogg, wav, flac) декодируется и переводится в 16 кГц моно.
2. [whisper.cpp](https://github.com/ggerganov/whisper.cpp) распознаёт слова, а DTW по «головам выравнивания» модели даёт точное начало каждого слова.
3. Распознанные слова сопоставляются с текстом автора (Needleman–Wunsch с нечётким сравнением слов). Поэтому тайминги ложатся на настоящий текст, даже если Whisper ослышался. Если слово не распознано, его время подставляется между соседними.

На тестовой записи начало строки отличается от настоящего в среднем на 0.07 с. Обработка занимает около 6 с на 30 с аудио на i5-12400F; песня на 3 минуты займёт примерно 35–40 с.

## Запуск

```powershell
cd aligner
.\start.ps1
```

Скрипт сам соберёт программу (если нужно) и скачает модель `ggml-small.bin` (~470 МБ). Пока окно открыто, кнопка «Авто-тайминг» в редакторе работает и на `localhost`, и на сайте в Vercel: браузер обращается к `http://localhost:8787` на вашем же компьютере.

## Сборка с нуля

Нужны:
- Rust: `winget install Rustlang.Rustup`;
- Visual Studio Build Tools с компонентом C++ (в них есть CMake);
- LLVM (нужен libclang): `winget install LLVM.LLVM`.

```powershell
.\build.ps1
cargo test --release   # проверки сопоставления и декодирования
```

`build.ps1` включает AVX2 и `/O2`: без них MSVC собирает whisper.cpp примерно в 8 раз медленнее.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `WHISPER_MODEL` | `models/ggml-small.bin` | Модель. `ggml-medium.bin` точнее, но в 2–3 раза медленнее |
| `ALIGNER_PORT` | `8787` | Порт (сервис слушает только `127.0.0.1`) |
| `ALIGNER_ORIGINS` | — | Дополнительные адреса сайта через запятую. Всегда разрешены karaokecraft.vercel.app, karaoke-six-dusky.vercel.app и localhost на любом порту |
| `ALIGNER_DEBUG` | — | Печатать каждое распознанное слово и время работы |

## Доступ с телефона и других компьютеров

`start.ps1` вместе с сервисом запускает бесплатный туннель Cloudflare (`cloudflared`, аккаунт не нужен). Туннель даёт вашему ПК публичный адрес вида `https://….trycloudflare.com`.

1. Aligner записывает этот адрес в Firestore (`config/aligner`) и обновляет его раз в минуту.
2. Сайт на любом устройстве читает адрес оттуда и отправляет авто-тайминг на ваш ПК.
3. При остановке (Ctrl+C) адрес стирается, и сайт перестаёт ждать этот сервер.

Ограничения:
- Работает, только пока ПК включён и окно `start.ps1` открыто. Песни обрабатываются по одной.
- Адрес меняется при каждом запуске, но сайт находит его сам.
- Адрес публичный, и любой, кто его узнает, может отправить запрос. Защита от злоупотреблений: только разрешённые сайты (CORS), лимит 60 МБ и 15 минут на файл, одна задача за раз.

Нужен cloudflared: `winget install Cloudflare.cloudflared`. Без него сервис работает только на этом компьютере. Отключить туннель можно переменной `ALIGNER_PUBLIC=0`.

## API

`POST /align` (multipart):
- `audio` — файл;
- `lyrics` — JSON-массив строк;
- `language` — `ru`, `en`, `kk` или `auto`.

Ответ:

```json
{ "language": "ru", "duration": 179.2, "elapsed_ms": 38000, "confidence": 0.92,
  "lines": [ { "index": 0, "start": 3.08, "end": 5.0, "confidence": 1.0,
               "words": [ { "text": "Я", "start": 3.08, "end": 3.3, "matched": true } ] } ] }
```

`confidence` строки — доля её слов, которые реально распознаны. Если она меньше 0.5, строку стоит проверить вручную; редактор помечает такие строки знаком «?».

`GET /health` возвращает `{ "ok": true, "model": "ggml-small.bin", "busy": false }`.
