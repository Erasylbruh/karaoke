# KaraokeCraft

Веб-платформа для создания, настройки и воспроизведения караоке-анимаций с синхронной подсветкой строк и экспортом видео с водяным знаком.

## 🚀 Стек технологий
- **Фреймворк:** [Next.js](https://nextjs.org/) 16 (App Router)
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS и собственные стили (тёмная тема)
- **Иконки:** Lucide Icons
- **Данные и вход:** Firebase Authentication + Cloud Firestore
- **Файлы:** Supabase Storage (загрузка по подписанным ссылкам через `/api/storage/upload`)
- **Аудио:** HTML5 Audio + Web Audio API (встроенный процедурный синтезатор для треков без аудио)
- **Экспорт видео:** Canvas + WebCodecs через [mediabunny](https://mediabunny.dev/); запасной путь — MediaRecorder
- **Авто-тайминг:** отдельный сервис на Rust и whisper.cpp, см. [aligner/README.md](aligner/README.md)

## 📦 Быстрый старт

1. Установка зависимостей:
```bash
npm install
```

2. Переменные окружения: скопируйте `.env.example` в `.env.local` и заполните (подробности — в [docs/DEPLOY.md](docs/DEPLOY.md)).

3. Запуск в режиме разработки:
```bash
npm run dev
```

4. Проверки и сборка:
```bash
npm run lint
npm run test:storage
npm run build
```

Приложение доступно по адресу [http://localhost:3000](http://localhost:3000).

## ✨ Возможности
- Синхронизация текста песни с музыкой (поддержка формата LRC и ручная расстановка таймингов на слух).
- Плеер с плавной синхронной заливкой строк, автопрокруткой и перемоткой по клику на строчку.
- Детальная кастомизация перед публикацией: шрифт, цвет активной строки, цвет текста, фон, размер шрифта, иконка/обложка, название, описание, теги.
- Скачивание видео с фирменным водяным знаком (форматы 9:16 для соцсетей и 16:9).
- Главная страница с поиском и сортировками (Рекомендованные, Популярные, Новые, Старые).
- Регистрация с согласием на обработку данных, подтверждение почты, личный профиль, удаление аккаунта со всеми данными.
- Жалобы на треки и отзывы, административная панель для модерации, ответов на жалобы и управления пользователями.
