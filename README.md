# KaraokeCraft

Веб-платформа для создания, настройки и воспроизведения караоке-анимаций в стиле Spotify Lyrics с синхронизацией строк и экспортом видео с водяным знаком.

## 🚀 Стек технологий
- **Фреймворк:** [Next.js](https://nextjs.org/) 16 (App Router)
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS (минималистичный темный UI в палитре Zinc)
- **Иконки:** Lucide Icons
- **Аудио:** HTML5 Audio + Web Audio API (встроенный процедурный синтезатор)
- **Экспорт видео:** HTML5 Canvas + MediaRecorder (с защитным водяным знаком)

## 📦 Быстрый старт

1. Установка зависимостей:
```bash
npm install
```

2. Запуск в режиме разработки:
```bash
npm run dev
```

3. Сборка продакшн-версии:
```bash
npm run build
npm start
```

Приложение доступно по адресу [http://localhost:3000](http://localhost:3000).

## ✨ Возможности
- Синхронизация текста песни с музыкой (поддержка формата LRC и ручная расстановка таймингов на слух).
- Плеер в стиле Spotify Lyrics с плавным скроллингом и перемоткой по клику на строчку.
- Детальная кастомизация перед публикацией: шрифт, цвет активной строки, цвет текста, фон, размер шрифта, иконка/обложка, название, описание, теги.
- Скачивание видео с фирменным водяным знаком (форматы 9:16 для соцсетей и 16:9).
- Главная страница с поиском и сортировками (Рекомендованные, Популярные, Новые, Старые).
- Регистрация, авторизация и личный профиль со списком публикаций и лайков.
- Административная панель для модерации треков и управления пользователями.
